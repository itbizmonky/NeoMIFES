# Issue: CSVグリッドのフィルタ行付近に表示異常が出る (P2 — 原因未調査、WI-16f以前から存在)

- **親文書:** WI-16f (`build_plan.md` §5) 実機ドッグフーディングで発見

## 事実

WI-16f(CSVセル単位クリック編集)の実機ドッグフーディング中、ユーザーからCSVグリッド(`Ctrl+Shift+G`)を開いた直後(セルをクリックする前)の時点で、フィルタ行(「フィルタ:」ラベル+編集欄)のすぐ下、実際のヘッダー行が表示される位置との間に、欠けた/重なったように見えるテキストが表示されるとの報告があった。

**WI-16fの変更が原因かどうかを切り分けるため、`git worktree`でWI-16f着手前のコミット(`27a212c`)をチェックアウトしビルドし、同じ操作(同一CSVファイルを開き`Ctrl+Shift+G`)で再現するかを確認した。結果、`27a212c`時点のビルドでも同じ症状が再現した。** このためWI-16fが原因ではなく、少なくともWI-16c(CSVグリッドUI実装、2026-08-19)以降のいずれかの時点から存在していた既存の表示バグと判断できる。

## 未調査事項

- 具体的な原因(ListViewのヘッダーコントロール自体の二重描画か、フィルタ行と`m_hwndList`のレイアウト計算の齟齬か、他の要因か)は本issue起票時点では特定できていない。
- WI-16c/16d/16eいずれの完了記録・ドッグフーディングでもこの症状は報告されていない — 過去のドッグフーディングがこの部分を見落としていたか、特定の環境/DPI設定/CSVデータでのみ再現するものと考えられる。
- 別issueの[検証環境固有の注意点](../../CLAUDE.md)として、実機検証は必ず可能な限りユーザー自身に行ってもらう運用に切り替えた経緯(2026-08-24)がある。今回はこの運用によってユーザーが直接発見した。

- 原因調査から着手する必要がある。`ui::CsvGridPane::onParentResized()`のレイアウト計算、`create()`での列/ヘッダー生成順序、DPIスケーリングの影響などを疑うべき箇所として優先的に確認する。
- 再現に必要な環境情報(DPI設定、Windowsバージョン等)をユーザーから追加で確認できると調査が進めやすい。
