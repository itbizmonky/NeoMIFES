# Issue: ミニマップのビューポートハイライトが折り返し(word wrap)有効時のビジュアル行密度を反映しない (P3 — 意図的な設計判断)

- **起票日:** 2026-09-03 (WI-21f、折り返し機能〔WI-21a〜e〕完了時の設計方針確認として起票)
- **対象:** `src/render/src/render_pipeline.cpp`(`RenderPipeline::drawMinimapViewportHighlight()`)
- **優先度:** P3 (折り返し機能自体〔P2〕の中でも非中核部分、実害は軽微かつ自己修正的)
- **対応 Phase:** 対応しない(意図的な設計判断、下記参照)

## 事実

`drawMinimapViewportHighlight()`は、ミニマップ上に現在の可視範囲を示すハイライト矩形を、以下の比率計算で描画している([render_pipeline.cpp](../../src/render/src/render_pipeline.cpp)):

```cpp
const auto [visStart, visEnd] = visibleLineRange();
...
const float rectTop = (static_cast<float>(visStart) / total) * heightDips;
const float rectBottom = (static_cast<float>(visEnd) / total) * heightDips;
```

`visStart`/`visEnd`は**論理行番号**(`visibleLineRange()`が返す`[startLine, endLineExclusive)`)、`total`は**文書全体の論理行数**(`totalLines`)。この比率計算は、折り返し(WI-21a〜e)が有効な場合、以下の前提が崩れる:

- 折り返し無効時: 1論理行=1画面行なので、「論理行の比率」=「画面上の位置の比率」が常に成立する。
- 折り返し有効時: 1論理行が複数のビジュアル行(画面上の描画行)に展開されうる。文書内で折り返し密度(1論理行あたりの平均ビジュアル行数)に偏りがある場合、「論理行の比率」と「実際のスクロール位置(ビジュアル行の比率)」が乖離する。

## 影響

折り返しが有効な状態で、極端に長い行(多数回折り返される)と短い行が混在する文書をスクロールした場合、ミニマップのハイライト矩形が実際のスクロール位置より不自然に大きく・または小さく表示されうる。例えば、文書の前半に極端に長い行が集中している場合、そこをスクロール中のハイライトは(論理行ベースでは狭い範囲でも実際のビジュアル行としては広い範囲を占めるため)本来より小さく表示される。

実害は軽微:
- スクロールを続ければ、ハイライトの位置・サイズは常に最新の`visibleLineRange()`から再計算されるため、位置のズレが蓄積することはない(その場その場では不正確でも、スクロールするたびに見た目は変化し続け、静止した誤表示のまま固まることはない)。
- ミニマップ自体は「大まかな文書内位置の把握」を目的とした補助UIであり、クリックによるジャンプ(`hitTestMinimap()`)は依然として論理行ベースで正確に機能する(本issueが指すのはハイライト矩形の表示のみ)。

## 対応方針: 対応しない(意図的な設計判断)

正確なビジュアル行数ベースの比率を計算するには、文書全体の各論理行について`visualRowCountForLine()`(WI-21c)を呼び出し合計する必要がある。これは**O(文書サイズ)の全文書走査**であり、CLAUDE.mdが明記する「10GBファイル対応」という既存コミットメントに反する——`maxVisibleLineLength()`のコメントが既に説明している「可視ウィンドウの範囲内のみを扱う」という、このファイル全体で一貫した設計方針からの逸脱になる。

WI-21計画策定時点でこのトレードオフは既に認識されており、「ミニマップは論理行ベースの近似のまま維持し、正確化はしない」という判断を(質問枠を使わず、技術的制約がほぼ一意に決まるため)自ら下し、承認済みプランに明記していた。WI-21f(折り返し機能の最終段階)でこの判断を再確認し、`drawMinimapViewportHighlight()`本体へ理由を明記するコメントを追加した上で、本issueとして正式に記録する。

## 完了条件

本issueは「対応しない」ことを記録するためのものであり、完了条件は設定しない。将来、以下のいずれかが発生した場合に再評価する:
