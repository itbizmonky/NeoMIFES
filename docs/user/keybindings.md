# NeoMIFES キーバインドリファレンス

最低限のリファレンスです。フルのユーザーガイドではありません。

## 設定ファイルの場所

すべて `%APPDATA%\NeoMIFES\` (通常 `C:\Users\<ユーザー名>\AppData\Roaming\NeoMIFES\`) 配下に保存されます。

| ファイル | 内容 |
|---|---|
| `settings.json` | フォント・タブ幅・行番号表示・ミニマップ表示・テーマ・自動保存間隔など |
| `keybindings.json` | キーバインド設定 (下記4プリセットのいずれか、または手動編集したカスタム設定) |
| `recent.json` | 最近開いたファイル一覧 (最大20件) |
| `search_history.json` | 検索/置換の履歴 |
| `autosave\` | 自動保存ファイル + クラッシュ復旧用インデックス |

いずれもファイルが存在しない・壊れている場合は既定値で安全に起動します。手動で削除しても構いません。

## キーバインドプリセット

コマンドパレット (`Ctrl+Shift+P`、VSCodeプリセットでは `F1` でも可) から `Keybindings: Preset (...)` を選ぶと、以下4種類のプリセットへ即座に切り替えられます (再起動不要、`keybindings.json` へ即時保存されます)。

- **NeoMIFES 標準** (既定)
- **秀丸エディタ風**
- **サクラエディタ風**
- **VSCode 風**

秀丸プリセットの一部コマンド (別名保存・検索の次/前へ・Grep・コマンドパレット・ブックマーク・タブ操作等) は、公式ドキュメントで既定値が確認できなかったため意図的に未割り当てのままです (「誤ったプリセットは無いより悪い」という方針による)。サクラプリセットも同様に一部 (タブを閉じる・タブ番号直接切替・コマンドパレット・上書きモード切替) が未割り当てです。

`keybindings.json` を手動編集した場合は、コマンドパレットから `Keybindings: Reload` を実行すると再起動なしで反映されます。

## NeoMIFES 標準プリセットの既定キー

| コマンド | キー |
|---|---|
| ファイルを開く | `Ctrl+O` |
| 新規作成 | `Ctrl+N` |
| 保存 | `Ctrl+S` |
| 別名で保存 | `Ctrl+Shift+S` |
| タブを閉じる | `Ctrl+W` |
| 次のタブ | `Ctrl+Tab` / `Ctrl+PageDown` |
| 前のタブ | `Ctrl+Shift+Tab` / `Ctrl+PageUp` |
| タブ 1〜9 へ直接切替 | `Ctrl+1` 〜 `Ctrl+9` |
| コピー / 切り取り / 貼り付け | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Y` |
| 上書きモード切替 | `Insert` |
| 検索 | `Ctrl+F` |
| 置換 | `Ctrl+H` |
| 次を検索 / 前を検索 | `F3` / `Shift+F3` |
| プロジェクト全体検索 (Grep) | `Ctrl+Shift+F` |
| 指定行へ移動 | `Ctrl+G` |
| コマンドパレット | `Ctrl+Shift+P` |
| アウトライン表示切替 | `Ctrl+Shift+O` |
| ブックマーク切替 | `Ctrl+F2` |
| 次のブックマーク / 前のブックマーク | `F2` / `Shift+F2` |
| タグジャンプ | `F12` |

他3プリセットの詳細な差分は `src/core/src/key_bindings_presets.cpp` を参照してください (このリファレンスと同じ値がソースコードそのものです)。

## 常に固定のキー (プリセットの対象外)

以下は `core::KeyBindings` のリマップ対象外で、どのプリセットを選んでも常に同じキーです。

### 継続的なテキスト編集キー

矢印キー・`Home`/`End`/`PageUp`/`PageDown`・`Backspace`/`Delete`・単語単位移動 (`Ctrl+←/→`)・矩形選択拡張 (`Shift+Alt+矢印`) など、押しっぱなしでの連続操作を伴うキーです。

### 基本編集コマンド (WI-12)

| コマンド | キー |
|---|---|
| 全選択 | `Ctrl+A` |
| 行複製 | `Ctrl+D` |
| 行を上へ移動 / 下へ移動 | `Alt+↑` / `Alt+↓` |
| 行削除 | `Ctrl+Shift+K` |
| 自動インデント | 改行時、前行のインデントを自動的に継承 (タブ/スペースいずれの設定でも追従) |

### マウス操作

- クリック: カーソル移動
- ダブルクリック: 単語選択
- トリプルクリック: 行選択
- ドラッグ: 範囲選択
- `Alt`+クリック: 矩形選択の開始点/複数カーソル追加
- ガター上のクリック: ブックマーク切替・折り畳みマーカーのトグル
